# Dream Count - Feminist Analysis

This is a seminar paper analyzing sexual exploitation and gender-based power in *Dream Count* by Chimamanda Ngozi Adichie. The paper focuses on the experiences of Chia, Zikora, and Kadiatou, using feminist theory as the main framework.

## Overview

- 📚 Topic: Sexual exploitation of women in *Dream Count*
- 🧠 Approach: Feminist literary analysis
- ✍️ Characters studied: Chia, Zikora, Kadiatou
- 🎯 Goal: To show how patriarchy, manipulation, and silence impact women’s lives in the novel
